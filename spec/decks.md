# 牌组

## 共用的规矩

1. **牌组名由各软件按自己的来源定。** 这里不规定顶层叫什么、分几层。现在各软件是这样起的：
   - ChatCards、Ask Free：`知识`（设置里能改）。
   - GetNewWord：单词进 `语言学习::<语言>`，知识片段进 `知识`。
   - 画布笔记：课程里的 PDF 跟库里的文件夹走，`课程::<课>::<课下面的文件夹整条路径>`（例如 `课程::ecp::Week 2::补充材料`），不在课程里的进 `知识`。
2. **建议**：层数少一点。章节、主题、分类优先写进标签（Anki 手册「Using Decks Appropriately」也这么建议）。这是建议，不是硬规矩。
3. **分隔符是 `::`。** 一节名字里自己带的 `::` 换成全角冒号 `：`，不让它多出一层。
4. **一节名字怎么清理**（`deckName(parts)` 做的事）：
   - 去掉控制字符（Unicode 类别 Cc），换行、制表符这些算空白的除外。
   - 连续的空白（Unicode White_Space，换行、制表符也算）并成一个半角空格，去掉首尾空白。
   - 清理后是空的那一节去掉（Anki 会把空的一节叫成 `blank`，我们不让它出现）。
   - 不截长度。
5. **牌组名用中文，不跟界面语言变。** 换界面语言不另建一套。
6. **按 id 记牌组，不按名字。** 软件建好或第一次找到一个牌组后，记下它的 id（AnkiConnect `deckNamesAndIds`）。以后先按 id 找现在叫什么，你在 Anki 里改了名，软件跟着你改的名字走；id 找不到（删了）才按名字找，还没有就建（`createDeck`），再记下新的 id（`resolveDeck` 做的事）。
7. **不碰别人的牌组。** 你自己建的和别的软件的，一律不动、不删。软件只删自己建的、已经空了的牌组。

## 和原规范的不同

原来三个仓库 DESIGN.md 里写的是「顶层 `语言学习` / `知识` / `读书`」「最多三层」。2026-11-22 起改成上面这样：顶层和层数由各软件按来源定，「最多三层」降为第 2 条的建议。原因是画布笔记的牌组要跟库里的文件夹走，课程下面的文件夹可能套好几层。
